DESIGN ALGORITHM - Floridian Tooth Records

Data Structure
    names: 1D array of String, one per family member; max 6
    teeth: 3D array of char
        [person][layer][tooth]
            Plane = person; max 6
            Layer = 2 rows: 0 = uppers, 1 = lowers
            Column = one char per tooth ('I', 'B', 'M'); max 8
        Irregular array
        Row sized to length of the string entered
    Both arrays are created in main with room for MAX_PEOPLE;
    only the first numPeople are used
    toothCounts: 1D array of int, size 3 (incisor, bicuspid, missing totals)


Constants:
MIN_PEOPLE = 1      MAX_PEOPLE = 6      MAX_TEETH = 8
NUM_LAYERS = 2      UPPER = 0           LOWER = 1
Tooth letters: INCISOR = 'I', BICUSPID = 'B', MISSING = 'M'
Menu letters: PRINT = 'P', EXTRACT = 'E', ROOT = 'R', EXIT = 'X'
Layer letters: UPPER_CHOICE = 'U', LOWER_CHOICE = 'L'
Tooth counts: NUM_TOOTH_TYPES = 3
    INCISOR_COUNT = 0, BICUSPID_COUNT = 1, MISSING_COUNT = 2
Name search: NOT_FOUND = -1
Output formats: PROMPT_FORMAT = "%-44s: ", ROOT_FORMAT = "%-22s%.2f%n"


MAIN (main)
    1. Display welcome message
    2. Input the family --> fills names and teeth, returns numPeople
    3. Run the menu loop
    4. Display exit message


1. DISPLAY WELCOME (displayWelcome)
    1.1 Print title and underline


2. INPUT FAMILY (inputFamily)
    2.1 Input number of people (validated: MIN_PEOPLE to MAX_PEOPLE)
    2.2 For each person i from 0 to numPeople-1
        2.2.1 Prompt for, read, and store the name of person i
        2.2.2 Prompt for the uppers of person i, then input a teeth string
            --> store as teeth[i][UPPER]
        2.2.3 Prompt for the lowers of person i, then input a teeth string
            --> store as teeth[i][LOWER]
    2.3 Return numPeople


2.1 INPUT NUMBER OF PEOPLE (inputNumberOfPeople)
    2.1.1 Prompt and read an integer
    2.1.2 While the integer is < MIN_PEOPLE or > MAX_PEOPLE
        2.1.2.1 Re-prompt "Invalid number of people, try again", read again
    2.1.3 Return the valid integer


2.2.2 INPUT A TEETH STRING (inputTeethString)
    (Used for both uppers and lowers; the caller prints the first prompt)
    2.2.2.1 Repeat
        2.2.2.1.1 Read a string
        2.2.2.1.2 Check that every character is a tooth letter
            (I/B/M, either case)
        2.2.2.1.3 If a character is not a tooth letter
            --> re-prompt "Invalid teeth types, try again"
        2.2.2.1.4 Else if the length is greater than MAX_TEETH
            --> re-prompt "Too many teeth, try again"
    2.2.2.2 Until every character is a tooth letter and the length is
        no more than MAX_TEETH
    2.2.2.3 Convert the valid string to a char array of the same length
        (stored as uppercase)
    2.2.2.4 Return the char array (teethRow)


3. MENU LOOP (runMenu)
    3.1 Repeat
        3.1.1 Input a menu option (validated P/E/R/X, either case)
        3.1.2 Depending on the option
            3.1.2.1 P --> Print the records
            3.1.2.2 E --> Extract a tooth
            3.1.2.3 R --> Report root canal indices
            3.1.2.4 X --> no action, the loop ends
    3.2 Until the option is X


3.1.1 INPUT MENU OPTION (inputMenuOption)
    3.1.1.1 Prompt and read a character (first letter, normalized to
        upper case)
    3.1.1.2 While the character is not one of P, E, R, X
        3.1.1.2.1 Re-prompt "Invalid menu option, try again", read again
    3.1.1.3 Return the valid character


3.1.2.1 PRINT THE RECORDS (printRecords)
    3.1.2.1.1 For each person i from 0 to numPeople-1
        3.1.2.1.1.1 Print the name
        3.1.2.1.1.2 Print one row: the uppers, labeled "Uppers:"
        3.1.2.1.1.3 Print one row: the lowers, labeled "Lowers:"


    PRINT ONE ROW (printRow; helper, used for both layers)
        Print the layer label
        For each tooth j in the row
            Print (j+1) ":" letter
        End the line


3.1.2.2 EXTRACT A TOOTH (extractTooth)
    3.1.2.2.1 Input a valid family member --> returns person index
    3.1.2.2.2 Input a valid layer (U/L) --> returns UPPER or LOWER
    3.1.2.2.3 rowLength = number of teeth in that person's chosen layer
    3.1.2.2.4 Count the teeth in that layer that are not 'M'
    3.1.2.2.5 If there are none
        3.1.2.2.5.1 Print "There are no teeth to extract in that layer"
    3.1.2.2.6 Else
        3.1.2.2.6.1 Input a valid tooth number (prompt "Which tooth number")
            --> returns a 0-based tooth index
        3.1.2.2.6.2 While the tooth at that position is already 'M' (missing)
            3.1.2.2.6.2.1 Input a valid tooth number again
                (prompt "Missing tooth, try again")
        3.1.2.2.6.3 Set that tooth to 'M'


    INPUT FAMILY MEMBER (inputFamilyMember; helper)
        Prompt "Which family member"
        Repeat
            Read a name
            Search the first numPeople names for a match (case-insensitive)
            If there is no match, re-prompt "Invalid family member, try again"
        Until a match is found
        Return the matching person index


    INPUT LAYER (inputLayer; helper)
        Prompt and read a character (first letter, normalized to upper case)
        While it is not U or L
            Re-prompt "Invalid layer, try again", read again
        Return UPPER for U, LOWER for L


    INPUT TOOTH NUMBER (inputToothNumber; helper, given a prompt and rowLength)
        Print the given prompt and read an integer
        While it is < 1 or > rowLength
            Re-prompt "Invalid tooth number, try again", read again
        Return the integer minus 1 (convert to 0-based index)


3.1.2.3 REPORT ROOT CANAL INDICES (reportRoots)
    3.1.2.3.1 Count the family totals I, B, M across the whole 3D array
        --> returned in toothCounts
    3.1.2.3.2 If I is 0 (no x^2 term, so it is not a quadratic)
        3.1.2.3.2.1 Print "Cannot find root canal indices without incisors"
    3.1.2.3.3 Else
        3.1.2.3.3.1 Compute the discriminant d = B*B + 4*I*M
        3.1.2.3.3.2 Compute root1 = (-B + sqrt(d)) / (2*I)
        3.1.2.3.3.3 Compute root2 = (-B - sqrt(d)) / (2*I)
        3.1.2.3.3.4 Print both roots to 2 decimal places


    COUNT TOOTH TYPES (countTeeth; helper)
        Make toothCounts with NUM_TOOTH_TYPES totals, all starting at 0
        For each person, each layer, each tooth
            Tally into I, B, or M by letter
        Return toothCounts


4. DISPLAY EXIT (displayExit)
    4.1 Print exit message (with smile)
